# CP-014G evidence — heartbeat supervision and reboot persistence

## Scope

Worker-only heartbeat supervision. No Azure, VPS, provider, or production mutation.

## Contract

- One heartbeat task and one supervisor task.
- Finished or frozen heartbeat tasks are recreated with bounded supervision.
- A live task is never duplicated.
- `/healthz` reports failure when the last server heartbeat ACK is stale.
- Docker Compose worker healthcheck calls `/healthz`; `restart: unless-stopped`
  provides container-exit and reboot persistence.
- Lifespan cancellation stops both tasks cleanly.
