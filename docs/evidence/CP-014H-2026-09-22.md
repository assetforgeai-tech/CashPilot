## Decisions

- `N` public IPv4 means `N` direct-only nodes, `N` hybrid direct plus `N`
  hybrid proxy nodes, and `N` proxy-only nodes when proxy capacity is enough.
- Insufficient proxy capacity blocks the lane; no silent reduction.
- Mysterium UDP is `56000-56100`.
- NKN uses TCP/UDP `30000-30005` and web view `:30000/web`.
- Wipter/UpRock UI access is tunnel-only; VNC/noVNC is not public.
- CashPilot UI and worker API remain private.
- ProxyBase.xyz is provider 16; phrase input only; count-only collector.

Focused matrix tests are required before PR. Unknown generic provider inbound
ports remain `inconclusive`; no broad public NSG rule is justified by this file.
