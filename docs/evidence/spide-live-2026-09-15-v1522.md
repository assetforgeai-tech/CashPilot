# Spide live verification (2026-09-15)

## Authority

- Spide dashboard API, authenticated from the server runtime, returned 40 devices.
- All 40 devices reported `online`.
- Device-key hashes were unique; raw keys are intentionally not recorded.

## Runtime

- Azure workers `118903` and `118904` run CashPilot worker `1.52.2` and report healthy.
- The server UI runs release `v1.52.2` and reports healthy.
- The Spide runtime preserves its per-instance data volumes and uses the official CLI.

## Defect and fix

- A transient Spide login `HTTP 500` could skip post-deploy registration because login had no retry.
- CashPilot now retries transient login failures three times with a five-second delay.
- The proxy sidecar previously received an unsupported top-level `route.sniff` field. The runtime now emits the compatible route action `{ "action": "sniff" }`.

## Limits

- This proves current online state and registration, not a provider earnings delta.
- Host-level firewall and the remaining provider network matrix remain separate production gates.
