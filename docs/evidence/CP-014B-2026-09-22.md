# CP-014B evidence — worker-resource authority inventory

## Scope

Declarative, database-free registry for every resource bound to a worker
generation. This task does not perform reclamation and does not change schema,
runtime, provider code, Azure, VPS, or production resources.

## Registered authorities

| Family | Authority | Worker-loss action | Post-release state | Preserved |
| --- | --- | --- | --- | --- |
| Proxy leases | `provider_proxy_leases` | `release_proxy_lease` | Lease released for a new worker generation | Proxy identity, sticky egress ownership, health |
| NKN wallets | `nkn_wallets` | `release_nkn_wallet_lease` | Wallet available; identity intact | Identity, credential, history |
| Myst wallets | `myst_wallets` | `release_myst_wallet_lease` | Wallet available; identity intact | Identity, credential, history |
| Provider runtime assignments | `provider_instances` | `retire_runtime_assignment` | Assignment retired; reacquisition required | Provider identity, earnings, audit history |
| Capacity reservations | `provider_proxy_leases.capacity_slot` | `release_capacity_reservation` | Capacity returned to pool | Provider identity, capacity history |
| Direct-only runtime | `provider_instances` | `retire_runtime_assignment` | Runtime retired; no proxy lease exists | Provider identity, earnings, audit history |

All release decisions use `worker_lost` as the reason. Account-pool
membership, EarnApp account ownership, PayPal ownership, credentials,
sticky egress ownership, proxy health, and earnings/history are preserved.
