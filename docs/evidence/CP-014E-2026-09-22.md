# CP-014E evidence — worker-loss dashboard visibility

## Scope

Dashboard-only visibility for the heartbeat worker-loss contract merged by
CP-014D. No worker, proxy, wallet, Azure, VPS, provider, or production mutation.

## Delivered

- `/api/workers` exposes heartbeat age, offline/reclaim thresholds, reclaim
  countdown, resource generation fencing state, and fresh-allocation requirement.
- Worker cards show offline/reclaim state, generation fencing, and durable
  reclamation count/latest timestamp.
- Fleet summary shows reclaimed worker count.
- Reclamation audit is read-only and sourced from
  `worker_resource_reclamations`.

## Policy invariants

- 3-minute stale status remains offline without reclaim.
- 15-minute stale countdown reaches zero before reclaim.
- Reclaimed generation is fenced and requires fresh allocation.
- UI does not infer current container state from an offline heartbeat.
