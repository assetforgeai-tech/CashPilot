## Scope

CP-004 adds a pure, read-only acceptance matrix for provider network canaries.
It does not probe workers, lease proxies, deploy containers, contact provider
dashboards, or mutate Azure/VPS/production resources. Live execution remains
CP-011.

`app/provider_canary_matrix.py` evaluates supplied evidence per provider and
groups results by the declared `ProviderRuntime.policy_group`:

- `PASS`: every required signal is present and true, with a rollback plan.
- `FAIL`: a supplied required signal is false.
- `INCONCLUSIVE`: evidence is missing, the provider is unknown, or rollback is
  not documented.

Required signals are lane-aware:

- all providers: egress, DNS, IPv6, direct-fallback, reboot persistence;
- proxy lanes: UDP behavior;
- proxy runtimes with a managed transport: watchdog behavior.

The matrix never treats absent packet-level evidence as success. Direct-only
providers do not inherit proxy UDP/watchdog requirements.
