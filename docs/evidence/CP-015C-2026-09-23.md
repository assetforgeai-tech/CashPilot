## Safety decisions

- Manual recheck remains non-rotating when the UI sends `rotate_dead=false`.
- A dead event is enqueued only after the durable three-cycle CP-015B state
  transition reaches `dead`; one transient failure does not rotate anything.
- Old bindings remain in place until the existing ACK, observed-egress, and
  CAS commit gates succeed. Failed rotation returns to the durable helper for
  persisted backoff.
- Queue memory is bounded independently of inventory size; the synthetic
  50,000-row test does not materialize a whole-pool task list.
- Probe timeout/control-plane uncertainty is recorded as inconclusive and does
  not mark an upstream dead.
- Persisted `next_probe_at` prevents each tick from rebuilding a 50,000-row
  probe workload. A leased proxy remains eligible for freshness checks even
  when its idle cadence is not due.
- Historical provider-specific allocation policies, including EarnApp and
  Pawns, are not generalized by this task.
