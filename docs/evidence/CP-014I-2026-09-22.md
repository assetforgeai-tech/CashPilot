# CP-014I evidence — Azure Cloud Shell worker script

Added `azure_create/cloud-shell-create-worker.sh`, a pasteable Azure Cloud
Shell script with no local-file dependency.

- Defaults: East Asia, `Standard_D8s_v4`, Ubuntu 24.04 (`Ubuntu2404`),
  Premium P20-equivalent `Premium_LRS` 512 GiB OS disk, and 20 static IPv4s.
- `IPV4_COUNT` is configurable (1–256); each address receives a Standard
  static public IP and NIC IP configuration.
- NSG is narrow and derived from the frozen matrix: SSH 22, Mysterium TCP
  4449, UDP 56000–56100, NKN TCP/UDP 30000–30005. Worker API/UI and VNC are
  not exposed.
- Cloud-init, release, image digest, API key, UI URL, and GHCR token are
  embedded in the generated custom-data payload; no repository/local file is
  read. Digest must be immutable `sha256:<64 hex>`.
- Supports read-only pre-inventory, dry-run command rendering, and explicit
  idempotency flags. SSH key authentication only; no password mode.
- No Azure mutation was executed during this task.
