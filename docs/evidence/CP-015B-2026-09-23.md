## Safety decisions

- Probe transitions never release, delete, or reassign a proxy.
- A newer probe generation fences older pending/running requests.
- Provider-instance requests capture the exact lease row; legacy worker
  assignments capture `assignment_version`.
- `inconclusive` and egress mismatch do not increment failure counters.
- A worker can have only one running rotation request at a time; a different
  provider instance does not bypass that fence.
- Migration of a pre-fence request table preserves history but cancels pending
  or running work with `migration_fence`, requiring a fresh probe event.
