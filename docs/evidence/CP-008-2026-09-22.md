## Scope

Account/token/collector policy only. No Chrome profile, live credential, token
sync, SSH, Azure, VPS, provider, or production mutation.

## Implemented contract

- Import decodes JWT `exp` and cookie expiration metadata without storing raw
  secrets in evidence.
- A known expired token or cookie is marked `AUTH_FAILED` with
  `auth_failure_kind=TOKEN_EXPIRED` and `needs_token_refresh=1`.
- Expired-token import never deletes or locks the account and keeps its node and
  proxy ownership untouched.
- Collection short-circuits known `TOKEN_EXPIRED` accounts before selecting a
  proxy or making a provider request; the result is sanitized and actionable.
- Existing durable account-operation queue, account API lock, auth-state
  classification, collector freshness reuse, and dashboard warning fields are
  preserved.
