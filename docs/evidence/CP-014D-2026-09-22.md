# CP-014D evidence — heartbeat scheduler and generation fencing

- Worker heartbeat remains the only liveness signal.
- At 3 minutes stale, worker becomes `offline`; resources remain leased.
- At 15 minutes stale, scheduler calls `reclaim_worker_resources` exactly once
  using token `worker-lost:<worker_id>:<resource_generation>` and CAS generation.
- Legacy independent NKN/EarnApp stale reclaim calls were removed from this
  scheduler path; CP-014C is the single atomic authority.
- Enrolled worker rows are retained. No Azure/VPS/provider mutation performed.

Focused tests: `tests/test_worker_offline_lease_reclamation.py`.
